# RetroMedia Warehouse — Simulator & Optimizer

A browser-accessible simulation for warehouse stocking and robot path optimization, handling LPs, CDs, and cassettes. Uses Smile (Java) for data cleaning and ML, Python Flask for backend, SQL for storage, and Vite + vanilla JS + Three.js for frontend visualization.

## Project Structure
- `smile-service/`: Java service for data cleaning and ML using Smile.
- `backend/`: Python Flask backend for orchestration and APIs.
- `frontend/`: Vite + vanilla JS + Three.js frontend.
- `database/`: SQL migration scripts.
- `sample-data/`: Sample datasets.
- `docs/`: Additional documentation.
